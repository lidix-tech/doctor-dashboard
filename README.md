# Doctor Dashboard

A web-based doctor dashboard for managing patients, prescriptions, exercises, follow-up dates, and patient pain reports.

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: OTP + JWT
- Styling: CSS

## Project Structure

```text
doctor-dashboard/
├── src/              # React frontend
├── backend/          # Express backend

```
